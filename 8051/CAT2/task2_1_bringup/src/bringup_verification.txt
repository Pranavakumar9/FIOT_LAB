1. COMPONENT & HARDWARE IDENTIFICATION
--------------------------------------------------------------------------------
Parameter                  Observation / Specification
--------------------------------------------------------------------------------
Target Microcontroller     Atmel AT89S52-24PU (40-pin Dual In-line Package)
Core Architecture          8-bit CISC MCS-51 core, 8 KB ISP Flash, 256B RAM
Nominal Core Frequency     11.0592 MHz Crystal Oscillator (XTAL1=Pin 19, XTAL2=Pin 18)
Machine Cycle Duration     12 clock periods = 12 / 11.0592 MHz = 1.085069 microseconds
Power Input Source         USB +5V Regulated Bus / External 9V DC Adapter via LM7805
Programmer Interface       10-pin standard ISP ribbon cable (SPI mode)
Programmer Signals         MOSI (P1.5), MISO (P1.6), SCK (P1.7), RST (Pin 9), VCC, GND
User Diagnostic LED        1x 3mm Green LED connected to Port 2 Pin 0 (P2.0 / Pin 21)
LED Active Topology        Active-LOW (Sink configuration): Anode -> 330R -> +5V, Cathode -> P2.0
Reset Circuitry            10 uF Electrolytic Capacitor to VCC, 8.2 kR Resistor to GND,
                           Tactile momentary pushbutton in parallel with capacitor.
